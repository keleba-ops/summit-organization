# Summit Organization

Static website for Summit Organization, published with GitHub Pages at
https://keleba-ops.github.io/summit-organization/

Built by iCentric Technologies.

## Notes
- This is a compiled single-page app (React). `404.html` is a copy of `index.html` so that
  direct links such as `/summit-organization/potential-partners` work on GitHub Pages.
- Paths are prefixed with `/summit-organization/`. If the site moves to a custom domain at the
  root, the prefix and the router base in `assets/index-*.js` must be removed.
